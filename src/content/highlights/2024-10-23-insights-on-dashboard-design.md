Few style guides go deep on dashboards, but the Baltimore City Data Fellows documentation includes a focused dashboard section.

It highlights practical concepts like grid-based layout, hierarchy, and reading patterns. It also points to deeper companion documentation, indicating a layered guidance model.

One useful reminder from this section is that reading flow assumptions vary by culture, so layout guidance should avoid treating a single pattern as universal.
