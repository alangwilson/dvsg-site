The Eurostat guide is not only about data visualization, but its chart chapter provides strong color guidance.

It documents core palette values in usable formats and then defines approved combination palettes plus tint and shade strategies. This makes color selection clearer for chart builders.

The guide also includes contrast-related notes, showing how palette systems and accessibility checks should be treated together.
